# Java Day 45 - Group Expense Splitter

## Description
A Java-based Group Expense Splitter that tracks shared expenses between three friends and calculates each person's contribution and balance.

## Features
- Add group expenses
- Display all expenses
- Calculate total group expenses
- Calculate equal expense shares
- Show who owes money and who gets money back
- Store expenses in a CSV file

## Files
- `Main.java` - Main Java program
- `expenses.csv` - Expense records

## How to Run
Keep both files in the same working directory.

Compile:

`javac Main.java`

Run:

`java Main`
